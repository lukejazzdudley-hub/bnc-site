French and Spanish introductions explain writing to a beat, recording takes and language packs. The detailed resource guides are currently in English.

App packs are separate from interface language

English is built in. Cadence’s app catalog includes 20 downloadable language packs, including French and Spanish. Download the packs you need while connected. The pronunciation-based rhyme engine runs on device. A rhyme pack does not mean every app screen is translated or every recording can be transcribed accurately.

Check a suggestion aloud in your own pronunciation. Language support does not remove accent, vocabulary or performance differences. Read the current store description and check the app’s language picker before relying on a specific pack.

Choose a free browser rhyme tool

Dictionnaire de rimes français · Diccionario de rimas en español. These independent public dictionaries are separate from app language packs; read each tool’s source and pronunciation limits.

The browser rhyme finder uses American English dictionary pronunciations and a limited original phrase bank. The web tool and app have separate engines. These translated pages do not add French or Spanish results to that browser tool.
