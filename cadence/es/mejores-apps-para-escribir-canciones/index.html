Mejores apps para escribir canciones en Android y iPhone

Qué app elegir según cómo compones

Cadence

Para escribir la letra sobre una base importada, buscar rimas y guardar las tomas junto a la canción. Incluye un paquete de rimas en español.

Song Cage

Para apuntar letras, notas de voz y acordes sin conexión. El editor web o de escritorio sirve para continuar el arreglo.

BandLab

Para construir una maqueta multipista en Android o iPhone. Revisa el límite de pistas y la duración del proyecto antes de grabar.

GarageBand

Para tocar instrumentos virtuales y grabar pistas en iPhone o iPad.

Prueba la misma estrofa en dos apps

  1. Importa una base que puedas usar y repite cuatro compases.
  2. Graba dos versiones de «Dejé tu mensaje sonando en el andén». Prueba a dejar un silencio antes de «andén» en una de ellas.
  3. Cierra y vuelve a abrir el proyecto. Comprueba si encuentras la letra, la base y las dos tomas.
  4. Si vas a seguir en otro programa, abre una exportación de prueba y comprueba el inicio de las pistas.

Qué puedes probar gratis
