What makes Cadence the best overall songwriting app

Cadence puts writing, rehearsal, recording, production and listening in one mobile workspace. Here’s what you can use in a real session.

  • Beat player with cue points. See the waveform, set independent A–B loop points and add named Song Map markers at timestamps such as a verse, hook or drop. Use those markers when placing sections. See how the beat player works.
  • 21 rhyme language options. English is built in, and 20 downloadable packs cover languages including Spanish, French, Hindi, Arabic and Brazilian Portuguese. Set which language comes first when you write across languages. See all rhyme languages.
  • A free local music player. Play locally available beats, demos and finished tracks offline, organize them into playlists and listen with the screen locked. Explore Cadence Listen.
  • Production Notes for sampling. Bring audio in from a file or extract sound from a video you can use. Save the sound with your notes and export it for a production session. See the sample workflow.
  • An interface built around the song. See highlighted rhymes beside the lyric, use the beat waveform to find your place and compare recorded takes before moving into the DAW. See the Cadence interface and watch the stem export.

How to write a song on iPhone

  1. Bring one idea. Start a draft with four lines, a Voice Memo or an instrumental you have permission to use.
  2. Loop the section. In Cadence, load the beat and set two loop points. Try the line ending out loud and adjust it before recording.
  3. Keep two takes. Record a straight delivery and one with a different rhythmic landing. Listen back and save the strongest line with its take.
  4. Check the handoff. If you finish in another DAW, check whether you need a single demo or aligned stems. Open a test export before moving your main project.

Compare the apps with one ten-minute session

Use the same four lines, spoken memo and instrumental in each app. Time how long it takes to have the words and the recording together. Record two deliveries, then reopen the project and find both versions. If your phone is often offline, save the project first and repeat the reopen test in airplane mode.

Finish by testing your actual handoff: a producer may need aligned stems, while a bandmate might need a chord chart. Write down any extra app or plan you needed. Android users can run the same exercise with our Android songwriting app comparison.

Check the same session on iPad

If you write on iPhone and finish on iPad, use the same small project on both devices before relying on that workflow. Check whether you can view the words beside the audio, find an earlier take, and open a test export. Test project and audio transfer separately. A lyric appearing on a second device does not prove that the recordings arrived with it. If you mostly finish at a desk, verify the exported file in the DAW you use there.
