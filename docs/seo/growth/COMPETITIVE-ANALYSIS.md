## What must be outperformed

1. **Immediate utility:** a dictionary query should reach a usable dictionary. A translated sales page alone misses this intent.
2. **Workflow evidence:** a type-beat query deserves real importing, looping, writing and recording, with recording/export limits disclosed. Feature lists alone are weak evidence.
3. **Compatibility clarity:** supported platform, current store destination, interface versus lyric language, and browser versus app engine must be explicit.
4. **Editorial independence:** demonstrations and independent reviews are more useful than repeating “best” on our own site. No review, backlink or native approval is assumed before it exists.
5. **Navigation and access:** indexable static explanations, reciprocal language links, working anchors, self-canonicals and accessible controls. Tool results remain client-side, while methods and examples are crawlable HTML.
