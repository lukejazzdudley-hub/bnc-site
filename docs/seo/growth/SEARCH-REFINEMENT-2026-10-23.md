# Search-intent refinement — 23 October 2026

This release improves existing pages that received observed search exposure.
Private Search Console metrics stay outside the public repository. It introduces
no new landing routes, dependencies, tracking fields or app changes.

## Changes and rationale

- Spanish and French dictionaries have descriptive main headings, static original
  example sentences and pairs, and practical lookup instructions. Readers and
  crawlers can access examples before loading a dictionary. Example buttons use
  the existing worker, select the documented perfect-match mode, then return
  focus to the search with instant scrolling.
- The songwriting-app comparison keeps its approved beat/bar/freestyle opening
  and ownership disclosure. A task-based section links to Android instructions,
  the type-beat workflow, free dictionaries and the recorded export walkthrough.
  Its title describes the actual eleven-tool comparison without a stale year.
- Android instructions name the existing app controls and distinguish Pro steps.
- The internal-rhyme guide now illustrates within-line, middle-to-end and
  cross-line placement, and distinguishes alliteration from rhyme.

Existing URLs, canonicals, alternates, source-check dates and accepted imagery
are preserved. Generated related-link labels change with the comparison title.
No competitor feature audit or native editorial acceptance is implied by this
release; existing source dates and limitations remain visible.

## Validation and evaluation

Every new French/Spanish perfect-rhyme pair is checked against its public data.
Tests also verify generated examples are in HTML, guide fragments exist, and
example actions preserve quick-search mode while using the documented mode for
editorial examples. Browser checks cover five affected pages at 320, 375, 390,
430, 768, 1024 and 1440 pixels and actual dictionary searches.

Compare complete periods around this deployment, excluding deployment day, with
equal lengths and matching weekdays when enough data exists. Keep the original
16–17 October rollout as a separate release boundary. Track page/query impressions,
clicks and position by country/device; compare recurring query cohorts separately
from newly appearing queries. Store clicks do not establish installs. This
release is an intervention, not evidence of improved ranking or acquisition.
