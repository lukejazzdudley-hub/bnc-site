# Regional Cadence editions on the existing canonical domain

Status: accepted from Luke's 16 October 2026 execution request and domain clarification.

Keep `brandnamechanges.com/cadence/` canonical and use `flowbycadence.com` as a
permanent redirect. Publish six English regional product editions with local
storefronts and useful writing guidance, linked through a download directory.
Use reciprocal hreflang and self-canonicals, with the existing product page as
global English and x-default. Keep the existing static generators as the content
system rather than migrating the working site to Webflow.

This preserves existing links, store review URLs and app-link association,
avoids duplicate domains and adds no hosting subscription. Source modules and
generated HTML must ship together. Language/region metadata does not establish
new app language support. Google may select a canonical or omit pages despite
valid markup; actual indexing and country-query performance need measurement.

Alternatives: a standalone Flow site would split maintenance and require a
migration decision; mass city/keyword pages would add low-value doorway risk;
Webflow would add a migration and new cost without resolving a current need.

No data-model migration. Existing legal, feedback and listening routes remain.
Validation covers reciprocal alternates, canonicals, source/visible FAQ agreement,
internal links, sitemap, local storefronts, responsive layout and existing suites.

The expansion also adds French/Spanish product introductions and a language directory. Include fr/es reciprocally in the product alternate cluster. The six regional pages are storefront/writing guides, not proof that those regions have the highest conversion value; prioritisation and future expansion remain measurement-led.
